# Gaming-Console
I chose to make a gaming console for my project. It will include a Raspberry Pi Zero 2w for the main brain of the console, and a screen. I will also include a second screen so that it can include animations which will be powered by a TENSTAR ESP32-S3-Zero (S3-FH4R2). It will open like a book and there will be two screens! One for playing on, and one for cute animations!! 

# What Project Is And How To Use It?
This is a handheld gaming console that I will be 3d printing! It will be powered by a Raspberry Pi Zero 2w for the main brain of the console, which will connect to the screen. It will also feature a second screen on the bottom next to the buttons so that it can include cute cozy animations while you play, it which will be powered by a TENSTAR ESP32-S3-Zero (S3-FH4R2). It will open like a book, and on the bottom base is where it will include the buttons!! To turn it on, it will include a power switch on the side, and for charging it has a charging port on the bottom! It will use RetroPie!

# Extra Button Installation:
So, on the provided tutorial, there are no XY and LR buttons that a usual GBA controller would have. Infact, the controller board also does not have it, which is why I will be adding them myself. On the schematic for the gaming console, I included four buttons on the left bottom of the screen to represent them and where they connect to the GPIO pins. Since the controller board does not have "gold spots" for them, I will be buying tactile switches which will be wired to the Raspberry Pi separately. These are like mini push buttons that will be pressed when you play, and send input to the Raspberry pi that the button has been pressed. To cover it I'm using plastic covers so it looks normal. The links to both are in my bom.csv!
